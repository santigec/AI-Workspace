# image-analysis

Inspecciona la imagen disponible y registra tamaño en píxeles y formato si pueden verificarse con herramientas.
Distingue lo visible de lo inferido: composición, objetos, colores, texto legible, logos y fondo.
Para una edición identifica qué debe conservarse y qué cambia según la solicitud.
No deduzcas DPI, dimensiones físicas ni transparencia real a partir de una vista previa.
Entrega un diagnóstico, restricciones de fidelidad y datos faltantes para la operación solicitada.
