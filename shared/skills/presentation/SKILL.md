# presentation

Define audiencia, decisión buscada, duración y formato.
Diseña una secuencia donde cada diapositiva aporte un mensaje sustentado; separa notas de exposición del contenido visual.
Usa datos y recursos provistos o verificables; marca los datos pendientes.
Si generas un archivo, revisa su renderizado para detectar recortes, superposiciones y texto ilegible.
Entrega la presentación o el guion según la solicitud, con fuentes y límites relevantes.
