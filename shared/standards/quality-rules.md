# Calidad

Preserva la intención, las referencias y las restricciones del usuario.
Distingue hechos observados, supuestos y datos pendientes.
Evalúa el artefacto resultante, no solo que la herramienta haya terminado.
Para impresión, valida especificaciones confirmadas; nunca declares PASS con verificaciones críticas pendientes.
Conserva el original y entrega archivos derivados por separado.
Un skill pasa de inicial a validado después de probarse con un caso real documentado en experiments.
