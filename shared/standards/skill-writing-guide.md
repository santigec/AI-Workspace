# Guía de skills

Cada skill vive en una carpeta con su nombre y contiene SKILL.md con frontmatter YAML: name y description.
La descripción indica cuándo usarlo. El cuerpo define decisiones, restricciones y salida.
Mantén el procedimiento corto; añade references, assets o scripts solamente si aportan valor.
Usa rutas relativas para referencias y explica cuándo consultarlas.
No presupongas herramientas, credenciales ni permisos. Declara las limitaciones cuando falten recursos.
Prueba un caso normal y uno con información incompleta antes de considerar estable el skill.
