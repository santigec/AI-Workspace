# Gobierno de herramientas externas de marketing

1. Registrar fuente, licencia, revisión evaluada, función, dependencias, costos y riesgos.
2. Revisar código e instrucciones antes de instalar; una estrella de GitHub no prueba seguridad ni adecuación.
3. Mantener credenciales fuera de Git y aplicar permisos mínimos y cuentas propiedad del negocio.
4. Exigir aprobación explícita antes de publicar, contactar, gastar o modificar cuentas.
5. Separar datos públicos de autorización de contacto; minimizar y documentar la finalidad.
6. Fijar versiones. Repetir revisión y pruebas antes de actualizar.
7. Proporcionar degradación segura: si el proveedor no está disponible, producir borrador o análisis y declarar la acción NOT_RUN.
