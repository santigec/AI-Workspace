# Marketing Operations

Flujo portable para una marca consumidora:

1. Cargar y validar el perfil de marca.
2. Usar `seo-operations` para descubrir demanda y oportunidades cuando corresponda.
3. Usar `local-lead-research` solo para investigación B2B con finalidad y campos definidos.
4. Usar `linkedin-marketing` para estrategia y borradores; publicar únicamente con aprobación y conexión autorizada.
5. Usar `agency-role-selection` cuando se necesite especialización adicional, seleccionando el conjunto mínimo.
6. Registrar fuentes, decisiones, costos y estados PASS, FAIL, SKIPPED o NOT_RUN sin exagerar automatización.
