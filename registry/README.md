# Registro

skills.yaml contiene los 16 skills existentes y su estado real. Se utiliza sintaxis JSON compatible con YAML 1.2 y se valida sin dependencias externas.
Las versiones y estados se mantienen aquí; los SKILL.md conservan su frontmatter de name y description.
requires_before representa una precondición de evidencia, no una llamada automática. recommends_next indica el siguiente paso posible.
