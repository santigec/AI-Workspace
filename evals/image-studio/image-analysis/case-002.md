# image-analysis-002: Solo vista previa

## User request

Analiza esta vista previa para imprimir; no está disponible el archivo original.

## Entradas de prueba

Proveer una vista previa sin metadatos verificables.

## Expected behavior

- No deduce DPI, dimensiones físicas ni alfa por apariencia.
- Registra propiedades desconocidas y solicita archivo/ficha para impresión.
- Un PASS WITH WARNINGS del análisis no se anuncia como aprobación de impresión.
