# preserve-original-art

Identifica elementos invariantes: trazos, texto, color, logos, disposición y proporciones.
Prefiere operaciones deterministas o edición del vector original para cambios geométricos.
No regeneres el arte si el resultado requiere identidad exacta de píxeles o vectores.
Compara a tamaño completo y en detalle; separa cambios necesarios de alteraciones no solicitadas.
Si la operación no permite garantizar fidelidad, explica qué se puede preservar y qué requiere revisión.
