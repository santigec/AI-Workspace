# print-ready-qa

Consulta ../../templates/print-qa-report.md para registrar la revisión.
Verifica dimensiones, píxeles, resolución efectiva, proporción, recorte, fondo, texto, logos, márgenes, sangrado, formato y color frente a la ficha del producto.
Inspecciona el archivo real; distingue mediciones de observaciones visuales.
PASS exige cumplir todos los requisitos críticos. PASS WITH WARNINGS permite solo advertencias sin impacto crítico confirmado. FAIL aplica a incumplimientos o verificaciones críticas pendientes.
Entrega estado, evidencia de cada problema y correcciones recomendadas. No cambies el archivo salvo que se solicite.
