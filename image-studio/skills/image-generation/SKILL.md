# image-generation

Extrae sujeto, composición, estilo, proporción, fondo y restricciones del brief.
Usa una herramienta de generación disponible; no presentes una descripción como si fuera un archivo generado.
Si hay referencia de identidad o marca, distingue requisitos de fidelidad de decisiones creativas.
Revisa el resultado frente al brief, incluyendo texto y objetos.
Para impresión consulta las especificaciones confirmadas del producto antes de afirmar que el archivo está listo.
