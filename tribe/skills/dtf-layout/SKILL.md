# dtf-layout

Consulta ../../knowledge/print-specs.md y la ficha de ../../templates/product-spec.md.
Confirma tamaño final, ancho útil de plancha, separación entre diseños, resolución, fondo y formato.
Mantén transparencia real cuando corresponda y evita residuos fuera del diseño.
No agregues fondo blanco, capa de tinta blanca ni espejo salvo que el flujo del proveedor lo requiera.
Entrega layout y tamaños de cada pieza, con observaciones para revisión del proveedor.
