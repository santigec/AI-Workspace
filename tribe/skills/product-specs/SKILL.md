# product-specs

Usa ../../templates/product-spec.md como ficha y consulta ../../knowledge/print-specs.md.
Consulta [el catálogo](../../knowledge/product-catalog/README.md) y resuelve product.id mediante [el registro](../../../registry/products.yaml).
Un registro unverified aporta propuestas, no requisitos confirmados. Para producción exige modelo, proveedor, fuente, fecha y campos production completos.
Identifica producto, modelo, proveedor y técnica; registra la fuente y fecha de cada especificación.
Distingue medidas verificadas de ejemplos. Solicita los datos críticos ausentes antes de preparar producción.
No extrapoles parámetros de equipos o materiales distintos.
Entrega una ficha confirmada o una ficha parcial con pendientes explícitos.
Para un borrador puede continuar el workflow de producto conforme a [resiliencia](../../policies/non-blocking-generation.md); la ficha parcial no habilita sublimation-layout de producción ni aprobación de QA.
