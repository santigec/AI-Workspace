# sublimation-layout

Consulta ../../knowledge/print-specs.md y la ficha creada con ../../templates/product-spec.md.
Usa dimensiones y plantilla verificadas del modelo exacto; respeta márgenes, uniones y zonas excluidas.
Adapta el arte sin deformarlo; confirma cualquier recorte de elementos importantes.
Confirma si el proveedor, RIP o usuario aplica espejo para evitar aplicarlo dos veces.
Entrega composición, dimensiones y pendientes; la preparación del arte no valida parámetros térmicos.
